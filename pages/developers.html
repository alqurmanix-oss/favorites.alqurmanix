تكامل AQX Favorites مع موقعك

أضف تجربة حفظ المحتوى إلى موقعك بسهولة. يوضح هذا الدليل أكواد التضمين الأساسية لزر الحفظ والأيقونة العائمة، مع فصل واضح بين كود كل مكوّن لتسهيل التركيب والصيانة.

أكواد التضمين

انسخ الأكواد كما هي وضعها في الموضع المناسب داخل صفحات موقعك. يفضّل وضع كود زر الحفظ في المكان الذي تريد ظهور الزر فيه، وإضافة كود الأيقونة العائمة مرة واحدة في الصفحة.

1. كود زر الحفظ

يعرض زر AQX Favorites داخل العنصر المحدد، ويمرر عنوان الصفحة الحالية وعنوانها النصي إلى واجهة التضمين.

<div id="aqx-save-button"></div>
<script>
(function () {
  const frame = document.createElement("iframe");
  const url = new URL(
    "https://favorites.alqurmanix.com/guest/embed.html"
  );

  url.searchParams.set("mode", "save");
  url.searchParams.set("url", location.href);
  url.searchParams.set("title", document.title);

  frame.src = url.href;
  frame.title = "AQX Favorites - Save";
  frame.width = "180";
  frame.height = "70";
  frame.style.cssText =
    "border:0;overflow:hidden;max-width:100%;";
  frame.setAttribute("allow", "storage-access");

  document.getElementById("aqx-save-button")
    .appendChild(frame);
})();
</script>
تأكد من وجود العنصر aqx-save-button في الصفحة قبل تنفيذ السكربت.

2. كود الأيقونة العائمة

يحمّل الأيقونة العائمة الخاصة بـ AQX Favorites. أضف هذا السكربت مرة واحدة فقط في الصفحة.

<!-- AQX Favorites - Floating Icon -->
<script
  async
  src="https://favorites.alqurmanix.com/guest/floating-widget.js?v=1"
></script>
<!-- End AQX Favorites -->
