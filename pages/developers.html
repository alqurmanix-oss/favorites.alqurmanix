مركز المطورين

ادمج AQX Favorites في موقعك بسهولة، وأتح لزوارك حفظ الصفحات والرجوع إليها من مكتبتهم الشخصية.

01

كود زر الحفظ

ضع الكود في المكان الذي تريد ظهور زر «حفظ» فيه. سيُمرّر عنوان الصفحة ورابطها تلقائيًا إلى AQX Favorites.

<div id="aqx-save-button"></div>
<script>
(function () {
  const frame = document.createElement("iframe");
  const url = new URL(
    "https://favorites.alqurmanix.com/guest/embed.html"
  );

  url.searchParams.set("mode", "save");
  url.searchParams.set("url", location.href);
  url.searchParams.set("title", document.title);

  frame.src = url.href;
  frame.title = "AQX Favorites - Save";
  frame.width = "180";
  frame.height = "70";
  frame.style.cssText =
    "border:0;overflow:hidden;max-width:100%;";
  frame.setAttribute("allow", "storage-access");

  document.getElementById("aqx-save-button")
    .appendChild(frame);
})();
</script>

رابط مفضلة الضيف

يمكنك استخدام الرابط المباشر لمفضلة الضيف في موقعك أو مشاركته مع الزوار.

https://favorites.alqurmanix.com/guest/index.html
إذا أردت إضافة بند باسم «محفوظاتي» أو «مكتبتي» داخل موقعك، اجعل هذا الرابط وجهة البند؛ وعند الضغط عليه ينتقل الزائر مباشرةً إلى مفضلة AQX Favorites الخاصة بالضيف.
02

كود الأيقونة العائمة

أضف السكربت التالي مرة واحدة داخل الصفحة لإظهار أيقونة AQX Favorites العائمة، ليتمكن الزائر من الوصول إلى تجربة الحفظ بسهولة.

<!-- AQX Favorites - Floating Icon -->
<script
  async
  src="https://favorites.alqurmanix.com/guest/floating-widget.js?v=1"
></script>
<!-- End AQX Favorites -->
